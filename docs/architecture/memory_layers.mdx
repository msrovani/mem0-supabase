# 🧠 Cognitive Memory Architecture

Mem0 Supabase Edition emulates the human cognitive system through a **12-layer** hierarchical architecture. This structure ensures that AI agents can sense, react, learn, manage knowledge, and **evolve their own identity**.

```mermaid
graph TD
    subgraph "Sensing & Reaction"
        SNS[Perceptual Memory - Sensory]
        RFX[Reflexive Memory - Metabolism]
    end

    subgraph "Buffer & Life"
        WKM{Working Memory - Resonance Buffer}
        EPI[Episodic Memory - Logs]
        LIF[Dynamic Lifecycle - Decay]
    end
    
    subgraph "Consolidation (Dreaming)"
        DRM[Recursive Distillation Engine]
    end
    
    subgraph "Knowledge & Association"
        SEM[Semantic Memory - Facts]
        PRO[Procedural Memory - Rules]
        GRA[Graphic Memory - Links]
    end

    subgraph "Enterprise & Authority"
        NEX[Authoritative Nexus]
    end

    subgraph "Sense of Self"
        EGO[12. The Ego - Meta-Identity]
    end

    subgraph "Remembrance Layer"
        REC[Recollection Engine]
    end

    Input --> SNS
    SNS --> RFX
    RFX --> WKM
    WKM --> EPI
    EPI --> LIF
    LIF -->|Dreaming Cycle| DRM
    DRM -->|Extract Core Beliefs| SEM
    DRM -->|Associate| GRA
    SEM --> NEX
    GRA --> NEX
    
    NEX --> EGO
    EGO --> REC
    
    Query --> REC
    REC --> NEX
    REC --> WKM
    REC --> EGO
```

> [!NOTE]
> **Unified Access**: The `Memory.process_interaction()` method acts as the central orchestrator (Smart Pipe), activating these layers to Recall (context) and Learn (storage) in a single flow.
